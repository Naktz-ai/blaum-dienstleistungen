## Editing

- Styles: `assets/style.css` · Script: `assets/site.js` · Images/video: `assets/`
- The pages are generated by `_build/build.py`. Texts for the subpages are stored in that file, and the homepage body is in `_build/home-main.html`. After editing, run:

```bash
python _build/build.py
```

Plain static HTML with no build step needed for hosting. Published with GitHub Pages.
